About RokiTOS

RokiTOS is an independent, custom-built Linux distribution born out of the need for a clean, highly responsive, and unbloated environment. Powered by a robust Debian Stable base, it integrates a modern Nordic aesthetic, finely tuned performance parameters, and all essential tools right out of the box.

System Architecture & Development Paradigm:

  • Built completely from bare-metal scratch using targeted debootstrap environments.
  • Stripped down initialization: Modified systemd targets optimizing structural unit-loading times.
  • Highly optimized live-boot compression framework using high-ratio SquashFS execution directly in RAM.
  • Integrated customized kernel configs ensuring seamless hardware passthrough under Proxmox VE KVM instances.

Key Features

Lightweight & Fast

Stripped of unnecessary background services and optimized for minimal RAM usage and instant response times.

Nordic Visual Theme

Pre-configured with a carefully selected dark theme, custom vector-based Papirus icon packs, and dynamic wallpaper shufflers.

Homelab Ready

Equipped with modern networking utilities, micro-containerization environments, and core tools tailored for server administration.

Development Roadmap

Stage 1: Core System ✅

Bootstrap optimization, structural configuration of hybrid EFI/BIOS boot loaders, base package injection.

Stage 2: Custom Installer ⏳

Implementation of an automated deployment engine for direct hardware installations without pre-live overheads.

Stage 3: Repository Setup 🚀

Launching dedicated package mirrors ensuring rolling security updates and customized application delivery.
